# 플레이어 기체 스킨: Fast Attack, Big Bullet

> 이 문서는 [A1-player-ship-skins.md](A1-player-ship-skins.md)의 한국어 번역입니다. 두 문서의 내용이 다르면 영어 문서를 기준으로 합니다.

A1 팀 · Player & Enemy Ship Variety · 관련: DR-5 (기체별 스프라이트), [A1-player-ships.ko.md](A1-player-ships.ko.md)

Fast Attack과 Big Bullet 기체마다 대체 스킨 세 가지를 제안합니다. 스킨은 스프라이트만 바꿉니다. 모든 스킨은 원본과 같은 13x8 그리드(게임 화면에서 26x16 px)에 좌우 대칭이며, 기체의 히트박스와 스탯은 그대로입니다.

| 기체 | 스킨 | 컨셉 |
|---|---|---|
| Fast Attack | A1 Arrow | 더 날렵한 화살촉 |
| Fast Attack | A2 Twin Fang | 쌍포 |
| Fast Attack | A3 Stealth | 외곽선 |
| Big Bullet | B1 Cannon | 굵은 포신 |
| Big Bullet | B2 Mortar | 둥근 선체 |
| Big Bullet | B3 Fortress | 성벽 |

아래 그리드에서 `█`는 채워진 픽셀, `·`는 빈 칸입니다. 비교를 위해 원본 스프라이트를 먼저 보여줍니다.

## 남은 과제

- **스킨 시스템:** 게임에는 아직 스킨 선택 기능이 없습니다. 스킨을 고르려면 메뉴 안의 자리(예: 기체 선택 화면)와 선택을 저장할 방법이 필요하고, 재화로 스킨을 해금한다면 Currency System 팀과의 연동이 필요합니다.
- **색상:** 모든 플레이어 기체는 한 가지 색(`Ship`의 `BASE_COLOR`, 초록)으로 그려집니다. 이 스킨들은 모양만 바꾸며, 스킨별 색을 쓰려면 코드 변경이 필요합니다.
- **파괴 스프라이트:** 원본 기체와 마찬가지로 스킨도 피격 시 공용 `ShipDestroyed` 스프라이트를 씁니다.
